# dot-lucide

すばらしいアイコンセットである [Lucide](https://lucide.dev) を、レトロなドット風（15 × 15 の点の並び）のアイコンに変換したアイコン集と、その変換スクリプトです。

Lucide と、その土台になった [Feather](https://feathericons.com) を作り、育ててきたみなさんに敬意を表します。Lucide のアイコンも、ここで変換したアイコンも、著作権は元のアイコンの作者に帰属し、元のアイコンのライセンスに従います（詳しくは「ライセンス」）。このリポジトリと変換したアイコンは、Lucide のプロジェクトとは関係のない個人が作ったもので、Lucide が作成・公認したものではありません。

変換済みの SVG が 1,857 個入っています（lucide-react 1.49.0 のアイコンから作成）。

## 変換したアイコン

`icons/` に、1 個 1 ファイルの SVG があります。ファイル名は Lucide のアイコン名と同じです。

- 枠は Lucide と同じ 24 × 24（`viewBox="0 0 24 24"`）で、点は 15 × 15 の並びです
- 色は `currentColor` です
- 点 1 個は、24px で表示すると 1.6px ほどです。点として見えるのは 32px 以上です
- Lucide の別名（`trash-2` など、ほかのアイコンと同じ形を指す名前）のファイルはありません。元の名前（`trash`）のファイルだけがあります

- 各ファイルの先頭に、元のアイコンとライセンスを書いたコメントが入っています

`icons/manifest.json` に、書き出したときの設定と、アイコンごとの名前・点の数・ライセンスの一覧があります。

変換したアイコンを利用するときは、元になった Lucide のアイコンのライセンスの条件に従ってください。詳しくは「ライセンス」にあります。

## サンプルページを見る

`index.html` は、全アイコンを一覧して、点の細かさ・線の太さ・点の形を変えながら見比べるページです。`icons.json` を読み込むので、ファイルを直接開かずにサーバー経由で開きます。

```bash
python3 -m http.server 8931 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8931/ を開きます。

## 変換のしくみ

変換の処理は `index.html` の中の JavaScript で、ブラウザの中で動きます。ライブラリは使っていません。どのアイコンも同じ 4 段階を通ります。

1. Lucide の線（path・circle・rect など）を、細かい折れ線にする
2. 触れ合っている線を部品にまとめ、部品どうしの関係（中心が重なる、等間隔に並ぶ、同じ形、など）を調べる
3. 部品ごとに、大きさと位置を点の間隔の倍数に寄せる
4. 寄せた形を線 1 本ずつ描き、どの点を灯すかを決める

アイコンの名前で処理を分けている所はありません。「円のまわりに短い線が 6 本以上あれば、円を小さくして線を伸ばす」のように、形の特徴で判定するルールだけでできています。ルールの一覧は [RULES.md](RULES.md) にあります。

## アイコンを書き出し直す

変換の処理を直したあとは、`icons/` を書き出し直します。Node.js と [Playwright](https://playwright.dev)（`@playwright/test`）が必要です。確認したのは Node.js 26 です。

1. リポジトリの直下でサーバーを立てる

   ```bash
   python3 -m http.server 8931 --bind 127.0.0.1
   ```

2. 別の端末で、書き出しのスクリプトを実行する

   ```bash
   PLAYWRIGHT_FROM=/path/to/project node tools/export-svg.mjs
   ```

   `PLAYWRIGHT_FROM` には、`@playwright/test` をインストールしてあるフォルダを指定します。

書き出しの設定は次のとおりです。ページの設定がこの値と違うと、スクリプトはエラーで止まります。

| 設定 | 値 |
|---|---|
| 点の細かさ | 中（15 × 15） |
| 元の線の太さ | 1.6 |
| 点を灯す基準 | 40% |
| 点の形 | 丸 |

## 変換の結果を確かめる

全アイコンを変換して、崩れの数を数えるスクリプトがあります。サーバーを立てた状態で実行します。

```bash
PLAYWRIGHT_FROM=/path/to/project node tools/check.mjs
```

次の数を表示します。変換できないアイコンか、左右対称の崩れが 1 個でもあると、終了コード 1 で終わります。

| 項目 | 数えているもの |
|---|---|
| 変換できない | エラーになる、または点が 1 つも灯らないアイコン |
| 左右対称の崩れ | 元の形は左右対称なのに、点にすると対称でないアイコン |
| 囲みの中のずれ | 元の形では囲みの真ん中にある部品が、点にすると真ん中から外れているアイコン |
| 大きさの食い違い | 元の形では同じ大きさの部品が、点にすると違う大きさになっているアイコン |
| 枠からのはみ出し | 部品の大きさや位置が、点の並ぶ範囲を超えて計算されているアイコン |

## Lucide の新しい版に追従する

`icons.json` は、lucide-react から取り出したアイコンの形とライセンスのデータです。lucide-react のフォルダを指定して作り直します。

```bash
node tools/extract-icons.mjs /path/to/node_modules/lucide-react icons.json
```

アイコンごとのライセンスは、lucide-react の `LICENSE` に載っている「Feather 由来のアイコン」の一覧から決めています。一覧には昔の名前で載っているものがあるので、スクリプトが別名をたどって今の名前に直します。たどれない名前があると、エラーで止まります。

作り直したあとは、次の 3 つを行います。

1. `LICENSE-lucide.txt` を、その版の `LICENSE` に差し替える
2. 著作権表示の年が変わっていたら、`index.html` の `LICENSE_INFO` と「ライセンス」の表、`tools/export-svg.mjs` の `manifest` の著作権表示を直す
3. アイコンを書き出し直す

## 分かっている崩れ

形の特徴で判定するルールでは直せていないアイコンがあります。

- `monitor-cog` などの小さな歯車は、歯が点 1 個より小さく、`monitor-dot` と見分けがつきません
- `case-sensitive` と `case-lower` の小文字の a は、角の取れた四角に見えます
- `footprints` は、足の形のくびれが出ません
- 囲みの真ん中にあるはずの部品が、半点ずれているアイコンが 130 個ほどあります。点の数の偶数・奇数が合わないときに起きます

アイコンごとに手で描いた形へ差し替える仕組みは、まだありません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `icons/*.svg` | 変換済みのアイコン |
| `icons/manifest.json` | 書き出したときの設定と、アイコンごとのライセンスの一覧 |
| `index.html` | 変換の処理と、サンプルページ |
| `icons.json` | Lucide から取り出したアイコンの形とライセンスのデータ |
| `RULES.md` | 変換のルールの一覧 |
| `tools/export-svg.mjs` | `icons/` を書き出し直すスクリプト |
| `tools/check.mjs` | 変換の結果を確かめるスクリプト |
| `tools/extract-icons.mjs` | `icons.json` を作り直すスクリプト |
| `LICENSE` | 変換のスクリプトとサンプルページのライセンス（MIT License） |
| `LICENSE-lucide.txt` | Lucide のライセンス全文（アイコンの形のライセンス） |
